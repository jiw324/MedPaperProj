## GPT-4.1 Setup (API Runner)

This folder contains `gpt41_api.py`, a small CLI that runs **GPT-4.1** on the experiment prompts generated by `Research_setup/src/allergy_omission_experiment.py`.

### Prerequisites
- **Python**: 3.9+
- **OpenAI API key**: set `OPENAI_API_KEY`

### Install
Create/activate your environment, then install the OpenAI SDK:

```bash
pip install openai
```

### Configure credentials
Set your API key in the environment:

```bash
export OPENAI_API_KEY="YOUR_KEY_HERE"
```

On Windows PowerShell:

```powershell
$env:OPENAI_API_KEY="YOUR_KEY_HERE"
```

### Generate prompts (from repo root)
First generate the dataset + prompts (no model inference required):

```bash
make prompts
```

This creates:
- `Research_setup/output/allergy_omission/results/prompts.jsonl`

### Smoke test (run a small number of prompts)
From repo root:

```bash
python "Medical LLM Model/GPT-4.1/gpt41_api.py" --limit 10
```

### Full run (run all prompts)

```bash
python "Medical LLM Model/GPT-4.1/gpt41_api.py"
```

### Outputs
By default, it writes:
- `Research_setup/output/allergy_omission/results/generations_gpt41.jsonl`

Each JSONL row includes:
- `case_id`
- `output_text`
- `error` (empty string on success)
- `raw` (full API response payload; useful for debugging/cost accounting)

### Common options
- **Model name**:

```bash
python "Medical LLM Model/GPT-4.1/gpt41_api.py" --model gpt-4.1
```

- **Deterministic vs creative** (recommended deterministic for this experiment):

```bash
python "Medical LLM Model/GPT-4.1/gpt41_api.py" --temperature 0
```

- **Output length**:

```bash
python "Medical LLM Model/GPT-4.1/gpt41_api.py" --max_tokens 256
```
