## Claude Sonnet 4.5 Setup (API Runner)

This folder contains `claude45_api.py`, a small CLI that runs **Claude Sonnet 4.5** on the experiment prompts generated by `Research_setup/src/allergy_omission_experiment.py`.

### Prerequisites
- **Python**: 3.9+
- **Anthropic API key**: set `ANTHROPIC_API_KEY`

### Install

```bash
pip install anthropic
```

### Configure credentials

```bash
export ANTHROPIC_API_KEY="YOUR_KEY_HERE"
```

On Windows PowerShell:

```powershell
$env:ANTHROPIC_API_KEY="YOUR_KEY_HERE"
```

### Generate prompts (from repo root)

```bash
make prompts
```

This creates:
- `Research_setup/output/allergy_omission/results/prompts.jsonl`

### Smoke test (run a small number of prompts)

```bash
python "Medical LLM Model/Claude 4.5/claude45_api.py" --limit 10
```

### Full run (run all prompts)

```bash
python "Medical LLM Model/Claude 4.5/claude45_api.py"
```

### Outputs
By default, it writes:
- `Research_setup/output/allergy_omission/results/generations_claude_sonnet45.jsonl`

Each JSONL row includes:
- `case_id`
- `output_text`
- `error` (empty string on success)
- `raw` (full API response payload)

### Model selection
Default model is `claude-sonnet-4-5`. You can override:

```bash
python "Medical LLM Model/Claude 4.5/claude45_api.py" --model claude-sonnet-4-5
```
