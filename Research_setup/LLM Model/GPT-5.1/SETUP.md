## GPT-5.1 Setup (API Runner)

This folder contains `gpt51_api.py`, a small CLI that runs **GPT-5.1** on the experiment prompts generated by `Research_setup/src/allergy_omission_experiment.py`.

### Prerequisites
- **Python**: 3.9+
- **OpenAI API key**: set `OPENAI_API_KEY`

### Install

```bash
pip install openai
```

### Configure credentials

```bash
export OPENAI_API_KEY="YOUR_KEY_HERE"
```

On Windows PowerShell:

```powershell
$env:OPENAI_API_KEY="YOUR_KEY_HERE"
```

### Generate prompts (from repo root)

```bash
make prompts
```

This creates:
- `Research_setup/output/allergy_omission/results/prompts.jsonl`

### Smoke test (run a small number of prompts)

```bash
python "Medical LLM Model/GPT-5.1/gpt51_api.py" --limit 10
```

### Full run (run all prompts)

```bash
python "Medical LLM Model/GPT-5.1/gpt51_api.py"
```

### Outputs
By default, it writes:
- `Research_setup/output/allergy_omission/results/generations_gpt51.jsonl`

Each JSONL row includes:
- `case_id`
- `output_text`
- `error` (empty string on success)
- `raw` (full API response payload)

### Common options
- **Model name**:

```bash
python "Medical LLM Model/GPT-5.1/gpt51_api.py" --model gpt-5.1
```

- **Deterministic vs creative**:

```bash
python "Medical LLM Model/GPT-5.1/gpt51_api.py" --temperature 0
```
